# PACA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A "PACA" screen under Pilihanraya where a coordinator builds the PACABA petugas roster (Pusat → Saluran → slots PA1/PA2/PA3/CA) seeded from a seat's scoresheet structure, saves it with history, and shares a public per-Pusat link where petugas self-register.

**Architecture:** The Pusat/Saluran structure is seeded from `Borang14Form.structure` via the existing `Borang14StrukturService::collapse()`. New tables `paca_forms → paca_pusat → paca_saluran → paca_slot` hold the roster; `paca_snapshots` holds save history (mirrors `Borang14Snapshot`). Slot/time logic lives in a pure `PacaSlotPlanner`. Admin routes are under `pilihanraya` (admin/super_admin, in-controller authz); the public form is reached by an unguessable per-Pusat token with no login.

**Tech Stack:** Laravel 12, Inertia, React 18, PHPUnit.

## Global Constraints

- **All user-facing text is Bahasa Melayu.** No i18n layer; hardcoded inline.
- **Unknown is not zero.** Optional counts/times stay `null`, never coerced to `0`/`''`. No `?? 0` on nullable figures.
- **Authorization lives in controllers, not middleware.** Admin methods: `$user = auth()->user(); if (!$user->isSuperAdmin() && !$user->isAdmin()) abort(403);` then Bandar-scope for plain admin.
- **Run tests with `php -d memory_limit=2G vendor/bin/phpunit`** (filtered: `-d memory_limit=1G`). NEVER `php artisan test` — it OOMs in Collision.
- **Baseline: 20 pre-existing failures** (`UserFactory` telephone). Only growth matters.
- **Never commit `public/build/`.** After `npm run build`: `git checkout -- public/build/ && git clean -fdq public/build/`.
- **Migrations run on every deploy** (`migrate --force`). New tables only — additive, safe. No reshaping existing tables.
- **Geography is string-matched** — reuse `kawasan_type`/`kawasan_id` exactly as `borang14_forms` does; add no FK to geography.
- Branch: `feature/paca`. Do not push to `main` during tasks.
- Spec: `docs/superpowers/specs/2026-07-23-paca-design.md`

## Interfaces from existing code (do not reimplement)

- `App\Services\Borang14StrukturService::collapse(?array $structure): array` → `['pusat' => [{row_id:string, dm:string, pusat:string, saluran_count:int, saluran_labels:array<string>}], 'undi_awal'=>bool, 'undi_pos'=>bool, ...]`. The `pusat` list is the PACA seed. Rows with `pusat === ''` (UNDI POS/AWAL sentinels) are NOT polling centres — exclude them from PACA.
- `App\Models\Borang14Form`: `kawasan_type`, `kawasan_id`, `jenis_pr`, `tahun`, `structure` (json), `source`, `status`. `Borang14Form::forKawasan($type,$id)` scope exists.
- `App\Models\KeahlianParti`: `id`, `nama` — party suggestions.
- `App\Support\MalaysianIc` — IC helpers (`birthDate()` returns null for unparseable IC).
- History pattern: `borang14_snapshots` = `{borang14_form_id, structure json, votes json, parties json, reason, created_by, created_at}`.

    $t->string('petugas_kp')->nullable();
    $t->string('petugas_tel')->nullable();
    $t->string('petugas_parti')->nullable();
    $t->timestamps();

    $t->id();

<?php
namespace Tests\Unit;

use App\Services\Pilihanraya\PacaSlotPlanner;
use Tests\TestCase;

class PacaSlotPlannerTest extends TestCase
{
    private PacaSlotPlanner $p;
    protected function setUp(): void { parent::setUp(); $this->p = new PacaSlotPlanner; }

    public function test_default_is_pa1_pa2_pa3_then_ca(): void
    {
        $slots = $this->p->defaultSlots();
        $this->assertSame(['PA1','PA2','PA3','CA'], array_column($slots, 'jawatan'));
    }

    public function test_defaults_start_at_8_in_two_hour_blocks_ca_open_ended(): void
    {
        $slots = $this->p->defaultSlots();
        $this->assertSame(['08:00','10:00'], [$slots[0]['masa_mula'], $slots[0]['masa_tamat']]);
        $this->assertSame('14:00', $slots[3]['masa_mula']);
        $this->assertNull($slots[3]['masa_tamat']); // CA ends "selesai"
    }

    public function test_last_slot_is_always_ca_after_relabel(): void
    {
        // Five slots must be PA1..PA4 + CA.
        $five = $this->p->defaultSlots(5);
        $this->assertSame(['PA1','PA2','PA3','PA4','CA'], array_column($five, 'jawatan'));

        // Relabel keeps order-derived jawatan even if input jawatan is wrong.
        $mislabelled = [
            ['jawatan'=>'CA','urutan'=>1], ['jawatan'=>'PA1','urutan'=>2], ['jawatan'=>'PA2','urutan'=>3],
        ];
        $this->assertSame(['PA1','PA2','CA'], array_column($this->p->relabel($mislabelled), 'jawatan'));
    }

    public function test_minimum_two_hours_enforced_for_pa_not_ca(): void
    {
        $this->assertFalse($this->p->minimumMet(['jawatan'=>'PA1','masa_mula'=>'08:00','masa_tamat'=>'09:30']));
        $this->assertTrue($this->p->minimumMet(['jawatan'=>'PA1','masa_mula'=>'08:00','masa_tamat'=>'10:00']));
        // CA (no tamat) is exempt.
        $this->assertTrue($this->p->minimumMet(['jawatan'=>'CA','masa_mula'=>'14:00','masa_tamat'=>null]));
        // A PA with no tamat yet (unfilled) is not a violation.
        $this->assertTrue($this->p->minimumMet(['jawatan'=>'PA2','masa_mula'=>'10:00','masa_tamat'=>null]));
    }
}
